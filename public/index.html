Initial Technical SEO + LLM Visibility Audit

How a search engine and an AI assistant read your site

Check a website

Enter a domain and press Run audit. To check particular pages instead, open Options and paste their URLs. A full check takes around 7–10 minutes.

  1. 1 Read robots.txt — the file that tells crawlers what they may visit
  2. 2 Pick up to 10 pages that represent the site
  3. 3 Fetch each one, twice: as sent, and as a browser renders it
  4. 4 Run every check
  5. 5 Score the result and write the report

The first step is a gate. If robots.txt blocks crawling or cannot be read, nothing else is checked — because nothing else would be reliable.
